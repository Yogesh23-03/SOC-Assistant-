# SOC Assistant extension

The shipped surface is an Operate interface: a narrow, light analyst case desk. The user approved this direction. The assigned laboratory-notebook concept is expressed through a linear case record, evidence sections and explicit authorization metadata rather than decorative lab imagery.

Typography uses Segoe UI and the platform sans stack for native browser-console familiarity; Consolas is reserved for IP addresses, IDs and evidence. Body text is 14px, supporting copy 12–13px, case headings 22px. The layout uses 20px horizontal inset and 24px section spacing, adapting wide panels to a 680px reading column.

Surfaces are #f6f7f5 and white; foreground #202c30; secondary #57666a; rules #dce2df. Teal #176b5b marks navigation and primary decisions. Amber, rust and red distinguish severity with text labels. Focus outlines use blue, separate from severity and approval color.

Queue rows use horizontal rules and generous click targets. A single case sheet leads from metadata to assessment, plain-text evidence and proposed response. Approval requires inline confirmation that repeats target and duration. Signed-out, disconnected, empty, expired, pending and completed states have explicit copy. Reduced-motion preferences are respected.

Verification: a 380px Chromium extension capture showed no horizontal overflow; the browser test checked hostile text and decision confirmation. The mechanical design detector returned no findings. Edge, additional widths and actual worker suspension still need the README acceptance checks.
